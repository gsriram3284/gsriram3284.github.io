# Sriram Ganeshan — academic website

A static academic website with research, publications, teaching, mentoring, contact information, and an academic CV.

## Publish with GitHub Pages

Publish the `main` branch from the repository root (`/`) in Settings → Pages. No build tools, package installation, or Jekyll configuration are required. The `.nojekyll` file keeps the site as plain HTML, CSS, and JavaScript.

- `index.html`: homepage and research profile, including the six-paper figure slideshow.
- `styles.css` and `app.js`: presentation and interactions.
- `cv.html`: full academic CV with all 52 publications and print/save-to-PDF support.
- `publications.json`: publication metadata.
- `favicon.svg`: site icon.

The portrait and original paper figures are served from Wix Media URLs. Paper links identify the original publications and figure sources.
